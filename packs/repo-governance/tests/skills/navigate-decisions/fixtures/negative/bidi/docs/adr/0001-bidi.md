# ADR-0001: Bidirectional control and non-printing character test

## Context

This record contains bidirectional Unicode controls in the Status field:
U+202E (RIGHT-TO-LEFT OVERRIDE) and U+202C (POP DIRECTIONAL FORMATTING).
The raw_value must preserve these bytes exactly. The display_value must visibly
escape them so the displayed text cannot spoof its apparent content. The
navigator must never silently normalize or strip these characters from raw_value.

A non-printing control U+0000 (NULL) appears here: .
A zero-width non-breaking space U+FEFF appears here: ﻿.

These must all be preserved in raw_value and visibly escaped in display_value.

## Decision

- **D1:** Bidi controls and non-printing characters are preserved in raw_value.
- **D2:** display_value visibly escapes unsafe bidi and non-printing controls.
