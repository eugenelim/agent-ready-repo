# ADR-0002: Target record with no mirror for one-sided test

- **Status:** Accepted
- **Supersedes:** none
- **Supersedes in part:** none
- **Superseded by:** none
- **Superseded in part:** none

## Context

ADR-0001 claims to supersede this record, but this record does not have
"Superseded by: ADR-0001". The absence of the mirror means the edge is
one-sided and must be unresolved on ADR-0001's side.

## Decision

- **D1:** This record is the target of a one-sided supersession claim.
