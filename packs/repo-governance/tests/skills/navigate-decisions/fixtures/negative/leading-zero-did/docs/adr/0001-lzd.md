# ADR-0001: Leading-zero D-ID test

- **Status:** Accepted
- **Supersedes:** none
- **Supersedes in part:** ADR-0002 D03
- **Superseded by:** none
- **Superseded in part:** none

## Context

"Supersedes in part: ADR-0002 D03" contains the D-ID "D03" which has a
leading zero. The spec requires D-IDs to have no leading zero (one to four
decimal digits with no leading zero). Therefore "ADR-0002 D03" is an
unparseable entry: its relationship has target=null, scope=[], and the entry
text as raw_value. It must never yield a checked edge.

## Decision

- **D1:** Leading-zero D-IDs are unparseable entries.
