# ADR-0001: Five-digit D-ID test

- **Status:** Accepted
- **Supersedes:** none
- **Supersedes in part:** ADR-0002 D12345
- **Superseded by:** none
- **Superseded in part:** none

## Context

"Supersedes in part: ADR-0002 D12345" contains the D-ID "D12345" which has
five digits. The spec requires D-IDs to have one to four decimal digits with
no leading zero. "D12345" exceeds the four-digit maximum, making the entry
unparseable: target=null, scope=[], raw_value is the entry text. It must
never yield a checked edge.

## Decision

- **D1:** Five-digit D-IDs are unparseable entries.
