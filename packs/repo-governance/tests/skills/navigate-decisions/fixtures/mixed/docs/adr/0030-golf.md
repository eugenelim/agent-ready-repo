## Context

Golf record covers: missing Status field. The header region holds no
"**Status:**" line. The navigator must return the missing-state marker rather
than treating this as a malformed record; a missing Status field is
explicitly permitted under the admission rules.

## Decision

- **D1:** Test infrastructure uses containerised runners only.

## Consequences

This record demonstrates the missing-status case without causing a failure.
