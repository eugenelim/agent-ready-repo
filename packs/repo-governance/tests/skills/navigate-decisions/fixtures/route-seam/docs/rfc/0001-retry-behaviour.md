# RFC-0001: Retry failed outbound calls with backoff

- **Date:** 2026-01-15
- **Status:** Accepted
- **Supersedes:** none
- **Supersedes in part:** none
- **Superseded by:** none
- **Superseded in part:** none

## Summary

Outbound calls that fail retry three times with exponential backoff.

## Decision

Accepted by the maintainers of every calling service.
