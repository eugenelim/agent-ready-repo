Maintainers decide by consensus. A change that no maintainer objects to within a reasonable review period goes ahead. If maintainers disagree, they keep discussing until they agree. Where one maintainer holds the project alone, that maintainer decides.

## Owned paths

These paths belong to the maintainers. Changing them follows the route below.

- `GOVERNANCE.md`

## Escalation

When maintainers cannot agree, any maintainer can ask for a written proposal. The maintainers then decide on that proposal and record the outcome.

## Changing this document

Change this document through the strongest route the repository has. Where the repository has an RFC process, use an RFC. Otherwise, record an owner decision. The maintainers adopt this document through their normal review.
