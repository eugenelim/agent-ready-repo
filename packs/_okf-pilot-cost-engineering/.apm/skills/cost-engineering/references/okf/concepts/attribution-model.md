# Cost attribution model

Use this concept when usage needs to be assigned to a product area, team, or
workflow from generic tags or metadata supplied by the operator.

Attribution evidence should be explainable from committed configuration,
request metadata, or an owner-maintained mapping. If multiple owners could
reasonably claim the same usage, report the ambiguity instead of choosing one.
