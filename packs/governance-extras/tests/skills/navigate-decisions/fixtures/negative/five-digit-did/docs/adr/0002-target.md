# ADR-0002: Target record for five-digit-D-ID corpus

- **Status:** Accepted
- **Supersedes:** none
- **Supersedes in part:** none
- **Superseded by:** none
- **Superseded in part:** none

## Context

ADR-0001 in this corpus references this record with a five-digit D-ID (D12345).
This record exists so the corpus is otherwise valid; the entry on ADR-0001 is
unparseable regardless of whether this record exists.

## Decision

- **D1:** Target record in the five-digit-D-ID corpus.
