# referents — craft-calibration tier

> This tier calibrates craft level for a surface with a declared genre (from the per-screen brief's `surface-genre:` field) — not a source of candidates during `explore`; accessibility floor not among these entries: `../design-review/references/quality-floor.md`.

The genre entries below are **study subjects, not prescriptive tools** — internalise the structural philosophy, the spatial grammar, the aesthetic philosophy each embodies. Do not copy the surface treatment; do not name any of these as required implementation tools; do not reproduce their values.

`assets/presets` holds three pre-filled starting directions (precedent referent only).

When `converge` grounds goals, use the entries below as the starting set for the **precedent** referent. For each goal, name which qualities of the reference you are drawing on — and which you are leaving. "Make it like Stripe" is not a ground; "borrow Stripe's typographic restraint and section-break discipline, leave the dark-mode palette and full-bleed hero" is.

## Genre tiers

Classifications: **quality invariant** (durable), **useful heuristic** (context-dependent), **model-era anti-pattern** + the period it describes.

**marketing** — Stripe marketing (conviction-led copywriting, full-bleed typographic design) *(model-era anti-pattern, 2020–2024)*; Linear homepage (developer-aesthetic minimalism, restraint as persuasion) *(model-era anti-pattern, 2022–2024)*; Vercel marketing (clean technical tone, performance as aesthetic) *(model-era anti-pattern, 2022–2024)*.

**documentation** — Stripe Docs (reference density and navigation at scale) *(model-era anti-pattern, 2020–2024)*; Vercel Docs (tutorial clarity and search-first architecture) *(useful heuristic)*; MDN Web Docs (type-consistency and machine-readability at reference depth) *(quality invariant)*.

**informational** — The Elements of Typographic Style (Bringhurst) for line length, leading, and scale principles *(quality invariant)*; Stripe's blog for code-adjacent editorial clarity *(model-era anti-pattern, 2020–2024)*; The Pudding for narrative and data-visualization integration *(useful heuristic)*.

**analytical** — Linear (high-density status layout and task-state clarity) *(model-era anti-pattern, 2022–2024)*; Retool (flexible widget hierarchy, data-dense spatial grammar) *(useful heuristic)*; Metabase (progressive disclosure in data exploration, approachable analytical aesthetic) *(useful heuristic)*.

**marketplace** — Airbnb (browse-first spatial warmth, social-proof hierarchy, map-integrated discovery) *(quality invariant)*; GitHub Marketplace (developer-tool catalogue aesthetic, badge-first trust signals) *(useful heuristic)*; npm (search-first, high-density reference information) *(useful heuristic)*.

**workspace** — Linear (keyboard-first productivity, task-state clarity, spatial minimalism) *(model-era anti-pattern, 2022–2024)*; Notion (context-persistence, collaborative editing state, content-as-structure) *(model-era anti-pattern, 2020–2024)*; Cursor (agentic UI legibility, HITL confirmation surfaces, code-adjacent aesthetic) *(model-era anti-pattern, 2023–2024)*.

**transactional-journey** — Stripe Checkout (trust signals, error recovery, form clarity) *(model-era anti-pattern, 2020–2024)*; Calendly (clean multi-step booking, friction-free time selection) *(useful heuristic)*; Apple Pay / Google Pay one-step flows (minimal-friction commitment surfaces, confirmation as design priority) *(quality invariant)*.
