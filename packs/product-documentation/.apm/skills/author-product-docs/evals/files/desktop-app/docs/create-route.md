# Create a route

Create a route so you can draw it on the map.

1. Choose **File** > **New Route**.
2. In **Route name**, type a name for the route.
3. Click on the map to place the first waypoint, then click again for each next waypoint.
4. Choose **Save**.

The route appears in the list on the left.
