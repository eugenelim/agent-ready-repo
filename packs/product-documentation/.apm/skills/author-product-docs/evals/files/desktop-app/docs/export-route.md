# Export a route

Export a route to a GPX file to load it on a handheld device.

1. Open a terminal.
2. Run `trailmap export --route "Ridge loop" --format gpx --out ~/routes/ridge.gpx`.
3. Copy the file to your device with `scp ~/routes/ridge.gpx device:/media/gps/`.

The GPX file is in the folder you named.
