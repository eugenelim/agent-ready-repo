# Language extension seams

The foundation recognizes two distinct extension-family identifiers:

- `python-pytest`
- `typescript-node`

Each is populated by a language topic resting on that ecosystem's own
authoritative documentation, and each is explicitly limited to the ecosystem and
version range its topic states. A claim evidenced from one ecosystem stays
inside it: it is not generalized into the portable floor, and it does not
transfer to the other family.

Do not translate Python conventions into TypeScript/Node guidance or the
reverse. Do not add an interpreter to the portable floor. Read the version range
a topic states before relying on it, and treat a claim carried outside that
range as unevidenced rather than as guidance.
