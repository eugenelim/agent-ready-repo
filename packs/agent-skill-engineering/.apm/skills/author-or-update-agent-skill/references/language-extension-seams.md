# Language extension seams

The foundation recognizes two distinct extension-family identifiers:

- `python-pytest`
- `typescript-node`

Neither has a language-specific topic body, executable helper, runtime
dependency, or package adapter in this slice. If a request needs one, return
honest language guidance unavailability and apply the relevant common
foundation topics for triggering, progressive disclosure, scripts, authority,
determinism, security, and failure behavior.

Do not translate Python conventions into TypeScript/Node guidance or the
reverse. Do not add an interpreter to the portable floor. A later governed
corpus slice must define each family independently with its own retrieval and
behavioral evidence before either becomes active.
