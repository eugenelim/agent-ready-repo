# Frame mode

Frame the skill before creating files.

Capture:

- realistic prompts that should and should not activate it;
- the outcome the skill must make observable;
- the minimum portable `SKILL.md` boundary and any genuinely conditional
  references, scripts, or assets;
- read, write, network, authentication, and external-side-effect boundaries;
- existing skill or repository contracts that must remain authoritative;
- success, failure, interruption, and clean-degradation evidence.

Prefer an action-oriented lowercase hyphenated name under 64 characters. Keep
the description discriminating; do not list every internal step in discovery
metadata. End with a proposed file tree and explicit non-goals. Create no file
and do not imply that agreement with the frame authorizes a later write.
