# Measured optimization

Optimization is authorized repair of a demonstrated weakness, not aesthetic
rewriting.

1. Freeze the applicable review checks, activation examples, representative
   tasks, outputs, and failure cases as the before baseline.
2. Name the observed failure and the metric or exact contract that should
   improve. Preserve unrelated supported behavior and declared non-goals.
3. Surface the confined root and exact write set. Revalidate confinement
   immediately before each write and serialize overlapping mutations.
4. Make the smallest coherent change. Do not add a new dependency, runtime,
   network operation, credential flow, or external side effect without its own
   authority and contract.
5. Run the identical before and after suite. Accept only a measured improvement
   with no regression in activation, portability, determinism, authority,
   security, or failure behavior.

If the result is neutral, worse, indeterminate, interrupted, or unverifiable,
report it and do not label the change an optimization. Cleanup denial does not
authorize a broader deletion attempt.
