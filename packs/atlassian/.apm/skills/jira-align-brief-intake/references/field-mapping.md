# Jira Align profile hints

The `jira-align-default` profile maps stable IDs, item type, modification date,
title/description, parent/child references, defect evidence, and repository
coordination facts into normalized intake. Organization-specific custom fields
require a new reviewed profile version.

Feature, Story, Defect, Program, hierarchy depth, owner, release, and item count
remain hints. They never determine artifact kind or readiness.
