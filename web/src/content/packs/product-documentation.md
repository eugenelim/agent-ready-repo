Product Documentation creates, revises, retrofits, audits, and verifies catalogue-facing product documentation. The `author-product-docs` skill supports five modes and uses Diátaxis as a page contract — no four-quadrant folder scaffold required. Install at repo or user scope; no directory skeleton is written on install.
