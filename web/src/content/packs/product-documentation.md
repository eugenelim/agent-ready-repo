Product Documentation equips your project with the `author-product-docs` skill — a single entry point for five documentation workflows: create a new guide, revise an existing one, retrofit legacy docs to Diátaxis, audit a doc set for page-contract violations, and verify rendered accuracy. Diátaxis governs how each page is shaped (tutorial / how-to / reference / explanation), not which directories you must create. Repo-scope by default.
