# Fieldkit pack

Fieldkit gives your agent skills for field research.

## Skills

- `fieldkit-reference`
- `field-interview-guide`
- `field-note-cleanup`
- `field-photo-captions`
- `field-route-planner`
- `field-safety-check`
- `field-sample-labels`
- `field-site-report`
- `field-weather-brief`

## Install

```
agentbundle install --pack fieldkit
```
