Facts, not narrative. Three things do not belong in the body:
  1. What you tried. No round counts, no findings tallies, no dead ends,
     no "then I discovered". Write what is true now.
  2. Method. A result is evidence; the run that produced it is not.
  3. The diff. The reviewer has it. Give them the outcome.

Budget: 40 lines of rendered body — a house convention, not a measured
optimum. Delete any section that would be empty. These comments do not
render, so leave them in place.
