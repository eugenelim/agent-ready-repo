# How-to guides

Task pages for installing, configuring, and extending the catalogue. Each one solves one job.

## Use the catalogue

- [Install agentbundle](install-agentbundle.md) — Install the command with pip, from a clone, or with APM.
- [Install packs for your agent](install-packs.md) — Install packs, or a whole profile, for your agent.
- [Configure agentbundle](configure-agentbundle.md) — Set a default agent and catalogue, and sign in.
- [Upgrade packs](upgrade-packs.md) — Upgrade installed packs without losing your edits.
- [Connect your tracker](choose-a-tracker-integration.md) — Bring Jira, Linear, or GitHub work into the repository.
- [Project intents and slices out to a tracker](project-slices-to-a-tracker.md) — Render intents and slices as tracker tickets, one way.
- [Start, remember, inspect, or refresh repository work](use-work-intake.md) — Start, remember, inspect, or refresh repository work.
- [Run a full inception for a new project](run-a-full-inception.md) — Go from a raw idea to a build-ready first spec.

## Extend the catalogue

- [Author a skill](author-a-skill.md) — Teach your agent a repeating task.
- [How to author a browser-automation skill](browser-automation-skill.md) — Author a skill that drives a browser.
- [Build a pack](build-an-org-stack-pack.md) — Give every team your organization's standards in one install.
- [Design a profile](design-a-profile.md) — Let one kind of person install the packs they need in one command.
- [Write a pack journey](pack-journey-authoring.md) — Show readers how to move through your pack.
- [How a catalogue works](create-a-catalogue.md) — Publish your own packs and profiles.
- [Create an external catalogue](create-external-catalogue.md) — Scaffold, validate, and publish a catalogue outside this repository.
- [Host on Artifactory](create-a-self-hosted-catalogue.md) — Host a catalogue on JFrog Artifactory.
- [Set enterprise defaults](configure-catalogue-enterprise-distribution.md) — Point every install at your organization's catalogue.
- [Roll out across an enterprise](roll-out-agent-ready-repo-across-an-enterprise.md) — Widen adoption one stage at a time.
