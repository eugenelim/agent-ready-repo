agent-ready-repo is an open source toolkit for AI-assisted software delivery. Your agent plans, builds, and tests a change, then stops for your review before it merges.

The workflows ship as packs. A pack is a set of skills and subagents your agent loads. Packs work in Claude Code, Codex, Gemini CLI, Cursor, GitHub Copilot, and Kiro.

## Install

<Tabs syncKey="install">
  <TabItem label="agentbundle">
    Install the CLI, then add the `core` pack from inside your repository:

    ```bash
    python -m pip install agentbundle
    cd path/to/your-repo
    agentbundle install --pack core
    ```

    `agentbundle` detects your agent. Add `--dry-run` to see every file before it is written.
  </TabItem>
  <TabItem label="Claude plugin">
    Add the marketplace once, then install a pack:

    ```bash
    claude plugin marketplace add eugenelim/agent-ready-repo
    claude plugin install desk-research@agent-ready-repo
    ```

    The marketplace carries packs you install for yourself. `core` and the other packs a whole team shares install with `agentbundle`.
  </TabItem>
</Tabs>

## Make your first request

Open your agent in the repository and ask for something you can check:

<Tabs syncKey="install">
  <TabItem label="agentbundle">
    ```text
    Fix the failing date parser test and show me the diff.
    ```

    The `core` pack plans the change, writes it, runs your tests, and sends the diff to an independent review. It stops before the merge. That decision is yours.
  </TabItem>
  <TabItem label="Claude plugin">
    ```text
    Research how other teams version their public APIs, with citations.
    ```

    The `desk-research` pack answers with sources you can open, a confidence rating for each finding, and the gaps it could not close.
  </TabItem>
</Tabs>

To see every stage end to end, [follow the install-to-ship walkthrough](/agent-ready-repo/docs/guides/#the-install-to-ship-walkthrough).
