Not sure which route fits? If you can name the change, [build a known change](/agent-ready-repo/docs/guides/core/how-to/start-or-remember-work/). If the product direction is still open, [shape an idea](/agent-ready-repo/docs/guides/product-engineering/how-to/shape-a-feature-intent/).

## New to Agent Ready Repo?

Every piece of work moves through four stages, and each one ends on a decision you make. [See the operating model](/agent-ready-repo/docs/guides/_shared/explanation/the-operating-model/) to find which stage your work is in, which packs help there, and where you decide.

![Four stages, left to right: Decide what to build, which ends when you pick the outcome. Shape it, which ends when you commit to build. Build it, which ends when you merge. Ship it, which ends when you ship it to production. Below them, architecture by stage: before any work, once per repository, architect-assess maps what exists and adapt-to-project or init-project writes reference.md, which every plan follows. Then you assess the area the work touches in Decide, design and revise the capabilities in Shape, and redraw the map after the merge in Build. Ship usually needs no architect skill.](/agent-ready-repo/docs/guides/_shared/explanation/the-operating-model-overview.svg)

When you're ready: [Install and configure your first workflow](/agent-ready-repo/docs/getting-started/). Start with a real task whose result you can check, and return here when you are ready to choose another route.
