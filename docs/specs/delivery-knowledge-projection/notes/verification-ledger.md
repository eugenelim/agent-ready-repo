# Delivery knowledge projection verification ledger

Execution observations for the approved spec and plan. The spec and plan stay
frozen; evidence goes here.

## T1: the read-only feed and pure projector

### Chosen seams (recorded before any behavior was green)

- **Admission seam.** One read-only accessor was added to the Slice 1 module:
  `replay_admitted_frames(raw)` in `_evidence_store.py`. It builds an unopened
  `EvidenceStore` over `os.devnull`, runs the store's own `_index_frames` on the
  bytes the caller supplies, and returns the admitted `(tx, records)` frames,
  the per-kind semantic index, and the superseded receipt IDs. `_index_frames`
  gained one optional output-only keyword, `admitted_frames`, which appends each
  admitted frame and changes no index, identity, or admission decision. The
  feed never calls `EvidenceStore.open()`, so nothing truncates a torn frame.
  A direct byte read with a second admission loop was rejected: it would copy
  the first-wins and `_validate_review_transition` rules and could drift.
- **Modules.** `_delivery_feed.py` (confined reads, snapshot, paging,
  `feed_page`/`render_page`), `_knowledge_projection.py` (pure
  `project_record`), and the CLI `delivery-fact-feed.py`, all under
  `packs/core/.apm/skills/work-loop/scripts/`.
- **Torn frame.** The feed cuts the bytes it read at the last newline before
  replay. The snapshot digest still covers the full length and sha256, so an
  append that completes a torn frame changes the snapshot.
- **Source resolution.** `_find_receipt_source` and `_find_report_finding` from
  `_evidence_store.py` resolve the report and finding; the review-policy
  fingerprint is the report's `lineage.review_policy_fingerprint`.
- **Schemas.** `knowledge-observation.v1` holds the shared identifier, spec
  path, repository path, and untrusted-text definitions; `delivery-fact-feed.v1`
  references them and states the page bounds once.

### First behavioral red (AC-0001: torn final frame)

The first cut of `_delivery_feed.py` handed the bytes it read straight to the
replay, with no cut at the last newline. Command:

```text
python -m pytest packs/core/tests/skills/work-loop/test_delivery_fact_feed.py -q -p no:cacheprovider
```

Result before the fix: `1 failed, 2 passed`. The failure was
`test_torn_final_frame_is_invisible_and_left_unrepaired`:

```text
AssertionError: assert [{'entry_kind': 'unread-source', 'ordinal': 0,
  'spec_path': 'docs/specs/alpha', 'reason_code': 'log-corrupt'}] == []
```

A torn tail made the whole log an unread source instead of staying invisible.
The superseded-receipt test passed on the first cut, because the supersession
check was already part of that cut.

### Green and deviations

- Fix: the feed cuts the bytes at the last newline before replay. The same
  command then passed. The contract, confinement, projector, and CLI suites
  pass (`test_delivery_fact_feed.py`, `test_delivery_fact_feed_confinement.py`,
  `test_knowledge_projection.py`).
- Deviation (roster): the schema parity suite extends the existing
  `tests/roster/test_delivery_contract_bundle.py` instead of adding a new roster
  file, so no `build-check.yml` step, `STEP_DISPOSITION` entry, or
  `.workspace-prune-protected.toml` entry is needed.
- Deviation (content refusal): the Slice 2 writers already refuse credentials,
  shebangs, and control characters, so a `content-refused` fact cannot be built
  through them. The feed-level test lowers the `knowledge-observation` profile
  cap to reach it; the projector table drives credential and email text directly.
- Deviation (page byte count): the page size is counted exactly, including the
  continuation token length, so a page ends only when the next entry would exceed
  the bound.
- Expected red outside T1: `tests/roster/test_t9a_conformance_rollup.py` projection
  byte-identity fails until the `.claude/` and `.agents/` projections are
  regenerated by self-host, which T1 did not run.
- Unrelated failure seen: `test_loop_engine.py::test_recover_engine_state_tmp_never_tracebacks_and_deletes_only_bad_content[deep-nesting]`
  (loop-engine tmp recovery, no file T1 touches).
