# Capture-work alias removal deferral anchor

## Disposition

The historical migration specification still names
`capture-work-alias-removal` as deferred work. Its approved successor is
[`capture-work-alias-removal`](../../capture-work-alias-removal/spec.md), which
is registered in the Platform Core ready queue.

This note preserves the historical deferral anchor without changing the
shipped specification or creating a second implementation target. Retire this
anchor only through a governed amendment that removes the deferral marker from
the historical specification.
