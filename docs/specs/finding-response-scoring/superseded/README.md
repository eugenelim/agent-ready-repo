# Superseded first run of `large-mixed`

Retained so `../result.md`'s comparison of two runs can be inspected rather than
taken on trust.

## What is here, and what it supports

- `large-mixed.fix-grammar.run1.raw.md` — the first run's verbatim answer.
- `large-mixed.fix-grammar.run1.md` — its classified dispositions, listed.
- `large-mixed.neutral-grammar.run1.raw.md` — the neutral arm's first answer,
  kept for audit only. Its rendering is believed to have changed between the two
  runs, so it is not treated as a repeat of anything; the earlier rendering was
  not retained, so that is a working-tree recollection rather than a record.

## What it does not support

**The first run's inputs were not retained.** No contemporaneous copy of the
rendering file it received, and no digest of one, exists here. The fix-arm
rendering is believed to have been unedited between the two runs — only the
neutral arm's F7 clause was changed — but that belief rests on the editing
history of an uncommitted working tree, not on retained bytes.

So this pair is an observation of two runs, not a verified controlled
replication, and `../result.md` claims no more than that.

These files sit outside `../transcripts/`. The corpus test enumerates that
directory and rejects any classified transcript the case set does not account
for, so `large-mixed.fix-grammar.run1.md` would be rejected there; the two
`*.raw.md` files are excluded from that enumeration and would not be.
