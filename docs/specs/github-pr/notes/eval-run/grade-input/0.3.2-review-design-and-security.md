### Important

**1. `src/export.py`, line 5 (RIGHT side)**
Quoted line: `    with open(os.path.join(REPORTS_DIR, path), "rb") as handle:`

Comment text:
> [security] `path` comes straight from `request.args["path"]` (line 4), and `os.path.join` keeps no boundary. A value like `../../etc/passwd` walks out of the reports directory. An absolute value like `/etc/passwd` makes `os.path.join` drop `REPORTS_DIR` entirely. Either way, any file the server can read is returned. The PR description says the spec limits exports to the reports directory, and nothing here enforces that. Suggested fix: resolve the path, then refuse anything outside the root:
> ```python
> root = os.path.realpath(REPORTS_DIR)
> target = os.path.realpath(os.path.join(root, path))
> if os.path.commonpath([root, target]) != root or not os.path.isfile(target):
>     raise PermissionError("export path outside reports directory")
> with open(target, "rb") as handle:
> ```
> Please also add tests for `../` paths, absolute paths, and a symlink inside the reports directory that points outside it.
