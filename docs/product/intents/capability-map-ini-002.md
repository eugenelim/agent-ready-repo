# INI-002 capability map

- **Status:** Draft
- **Level:** capability

## Outcome

Platform Core has a current capability map that distinguishes shipped platform
capabilities, remaining adoption capabilities, and work owned by other active
initiatives.

## Opportunity

The accepted RFC contains a delivery sequence and the repository now ships the
mapping workflow, but no living INI-002 capability artifact reconciles that
plan with current repository state.

## Assumptions

- Shipped specifications are evidence of capability state, not a reason to
  recreate historical shaping outputs.
- The map should retain explicit ownership boundaries with other initiatives.
- The map feeds the INI-002 initiative brief rather than directly authorizing
  implementation.
