## Blockers

**1. `AC-0005A` does not gate credential-bearing environment or service-auth surfaces.** `docs/specs/plan-evolution-experiments/spec.md:97-104`, `docs/specs/plan-evolution-experiments/spec.md:327-331`. A malfunctioning or prompt-injected collaboration worker that already has the shared agent/tool surface can read credential-bearing environment variables, runtime sockets, or broker-accessible configuration that protected-path denials do not cover, then copy sensitive material into its terminal report or raw run receipt during one of the released starts. Fix: the release criteria must fail closed unless the controller can observe that workers cannot read credential-bearing environment, service-auth socket, broker, or protected-configuration surfaces and cannot persist token material in reports; when those properties cannot be observed, the run set remains unreleased or is downgraded to a non-secret-bearing manual case study.

## Concerns

**2. Filesystem confinement is allowed to drift from the blessed helper.** `docs/specs/plan-evolution-experiments/spec.md:360-363`, `docs/specs/plan-evolution-experiments/plan.md:82-86`, `docs/specs/plan-evolution-experiments/plan.md:111-115`, `docs/specs/plan-evolution-experiments/plan.md:282-286`. A malicious task archive, agent report, or model-derived sink path can exploit a hand-rolled disposable-root confinement gap before grading or reporting consumes bytes, even if the current prose lists the same classes of symlink, hard-link, reparse, path-loop, and identity-change refusals. Fix: the active acceptance criteria must bind repository-confined filesystem handling to `agentbundle.catalogue_tooling.file_safety` and must require any disposable-root equivalent to stay contract-equivalent to that helper, with parity evidence for archive members, link-like entries, hard links, junctions/reparse points, path loops, containment, and open-time identity changes.

**3. Retrieved Hacker News and linked-resource text lacks a data-only prompt-injection criterion.** `docs/specs/plan-evolution-experiments/spec.md:357-359`, `docs/specs/plan-evolution-experiments/plan.md:143-146`, `docs/specs/plan-evolution-experiments/plan.md:653-659`. An HN commenter, source-article author, linked-resource owner, or `pure.md` recovery page controls text that may be summarized into the research context, and without an acceptance criterion preserving data-only framing that text can try to change hypotheses, scoring, release decisions, or hidden-material handling. Fix: the source-capture criteria must require fetched article, comment, linked-resource, and recovery bodies to remain delimited untrusted data with provenance, bounded summaries only, no instruction authority, and owner-approved amendment before source text can alter run definitions, scoring, or release state.

**4. Grading and regression execution lacks hard exceptional-condition caps.** `docs/specs/plan-evolution-experiments/spec.md:336-338`, `docs/specs/plan-evolution-experiments/plan.md:117-120`, `docs/specs/plan-evolution-experiments/plan.md:554-559`. A worker-controlled candidate can make hidden oracle or regression execution hang, fork, or emit excessive artifacts during grading; recording duration and output digests after execution does not prevent local denial of service or incomplete terminal accounting. Fix: the acceptance criteria must require every grading, regression, repair, and candidate-executing command to run under controller-enforced timeout, process-tree cleanup, output and artifact size limits, isolated working directory, no shell expansion, and an explicit terminal status when any cap fires.

**5. Raw `.context` retention is not privacy-bounded.** `docs/specs/plan-evolution-experiments/spec.md:261-263`, `docs/specs/plan-evolution-experiments/plan.md:528-530`, `docs/specs/plan-evolution-experiments/plan.md:548-550`. A worker or fetched source can place personal paths, identifiers, credential-shaped strings, or sensitive snippets into raw prompts, candidates, returns, or phase receipts, and the ignored workbench persists them outside the tracked report's redaction and generic-placeholder rules. Fix: the criteria for raw workbench artifacts must require retention bounds and privacy screening before persistence or before reuse, with suspected personal or secret-bearing content quarantined behind digest-only references and tracked evidence kept generic.
