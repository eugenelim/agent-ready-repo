## Blockers

**1. Run 0 launch gate contradicts the document-only launch rule.** `docs/specs/plan-evolution-experiments/spec.md:387-391`, `docs/specs/plan-evolution-experiments/plan.md:44-49`. The AC says Run 0 must fail closed before launch when web, network, delegation, approval escalation, or external-messaging tools are exposed, but the plan says that same exposed surface is recorded while the result remains non-inferential, so T8 cannot both launch eight real terminal document subjects and obey the AC when such tools are exposed. Fix: make the document-only branch have one launch rule: either exposed tools stop collection before launch and downstream starts are removed or stopped, or exposed tools are a recorded non-inferential limitation while secret-bearing input and requested or observed forbidden use still stop the subject.
