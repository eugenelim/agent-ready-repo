# Architecture assessment corpus source packets

Living maintenance evidence for the architect pack's `architecture-lenses` OKF
bundle. The directory under `concepts/` mirrors each canonical concept path.
Packets trace material synthesis claims to independent sources, retain
counter-evidence and confidence downgrades, and are updated as references age.

These packets are not shipped agent instructions and never contain adopter
organization content. Canonical portable guidance lives under
`packs/architect/okf/architecture-lenses/`; generated router files remain build
output.

## Packet contract

Each packet declares its concept path, confidence, living lifecycle, material
claims, at least three independent sources for moderate/high confidence,
counter-evidence, licensing/reuse posture, known unknowns, and freshness review.
