## Highlights
- Install Terraform authoring and release workflows together with platform-engineering, with no required dependency.

## Changed
- `platform-engineering` 1.0.0 replaces `iac-terraform` and `release-engineering`. Both old packs are removed; the rename map points both old names at `platform-engineering`. Skill, agent and contract names stay unchanged.
- The combined pack has no required dependency. Core remains an optional integration.

Follow the [migration and rollback guide](../../../guides/platform-engineering/how-to/migrate-from-iac-terraform-and-release-engineering.md):

1. Record each old pack's adapter and scope. Choose one scope per adapter for `platform-engineering` before uninstalling if the old packs use different scopes.
2. Uninstall every installed `iac-terraform` and `release-engineering` row across all adapters and scopes before installing the new pack.
3. Install `platform-engineering` once per adapter at its chosen scope, from a catalogue source containing the new pack. Update older catalogue pins first.

Uninstall keeps edited files. Install writes new content beside kept edits as `.upstream` companions. There is no automatic backup; files you delete during migration are not recovered.

To roll back, uninstall every `platform-engineering` row across all adapters and scopes first, then merge and delete each `.upstream` companion. Then reinstall each old pack at its original adapter and scope from the catalogue pinned to `42849d1e7`. The migration guide gives the exact commands; kept edits survive rollback.
