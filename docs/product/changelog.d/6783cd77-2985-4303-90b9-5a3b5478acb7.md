## Highlights
- Architect-design screens subsystem and change designs for module shapes the next contributor is likely to misuse, writes contracts from real call sites first, and asks for a second design shape that differs in structure.

## Changed
- `architect-design` has a new reference that lists eight module shapes to avoid, such as a shallow module or two modules writing the same state. It checks each candidate shape against them.
- Each new or widened contract now starts from two or three call sites a real caller would write.
- The alternatives guide asks for a second shape that differs in structure, or a reason why only one shape works.
- `architect-review` checks a design doc for the same three things.
