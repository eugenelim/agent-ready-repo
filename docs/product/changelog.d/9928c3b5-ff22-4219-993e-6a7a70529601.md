## Highlights
- Architect-design can write a solution repo's shared system reference and offers a physical architecture with a bill of materials after a design.

## Changed
- `architect-design` has a solution reference mode for a coordinating repo with no app code. It writes the system C4 view, domain boundaries, shared contracts, and the rule each component repo follows, one confirmed section at a time. A repo with app code still uses Core's `adapt-to-project` or `init-project`.
- After a design converges, `architect-design` offers a physical architecture and bill of materials. Each line names its exact cloud service SKU, container image URI, open-source package, node hardware, network link, or licence. Each price is cited or marked unpriced and left out of the total.
- An architecture change gets a delta bill of materials with the net monthly change.
