## Highlights
- Architect-design can write a solution repo's shared system reference and offers a physical architecture with a bill of materials after a design.

## Changed
- `architect-design` has a solution reference mode for a coordinating repo with no app code. It draws the whole-system diagrams and the boundaries between domains, and writes the shared rules each component repo follows.
- It writes that reference one confirmed section at a time. A repo with app code still uses Core's `adapt-to-project` or `init-project`.
- After a design is accepted, `architect-design` offers a physical architecture and bill of materials. Each line names the exact item, such as a cloud service plan or a container image.
- Each price is cited, or marked unpriced and left out of the total.
- A change to an existing system gets a delta bill of materials with the net monthly change.
