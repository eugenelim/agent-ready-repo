## Highlights
- Catalogue publishers can compare a release with a prior archive, and a release version is never silently replaced.

## Changed
- `agentbundle catalogue package --compare <archive>` lists every pack and profile added, removed or changed since a prior release, and flags a pack whose content changed under the same version. `--format json` writes the same result as one JSON object on stdout.
- Packaging now refuses to replace a release archive that already exists, for both the runtime and source flavours. The command exits 2 and changes nothing. `--force` replaces the release on purpose.
- `catalogue-manifest.json` lists a `path` and a `digest` for each pack and profile, and `catalogue verify --archive` checks them. The manifest `schema` stays `2`.
- Breaking: the refusal exits 2, where it exited 1. The subcommand rejects shortened options such as `--forc`. Each `profiles` entry is now an object, not a name string.
