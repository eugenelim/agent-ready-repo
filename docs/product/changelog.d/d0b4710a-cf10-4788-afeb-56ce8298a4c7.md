## Highlights
- The work-loop's spec-approved and plan-approved gates can now be parked with `work-supervisor.py park` and listed with the read-only `gates` command, so the controller can work other independent specs while an approval waits. `gates` shows the exact spec and plan digests, the commit, read commands that print exactly the stored bytes, the consequence of each answer, and whether the gate is pending, stale, or invalid.
- `start` now needs `--approved-spec-digest` and `--approved-plan-digest` whenever it records an approval, and refuses if either file changed from the approved revision.
- A parked gate is never approved by default.
