## Highlights
- A work-loop reviewer finding that carries a command now gets a recorded assessment from the controller's run of that command: a run that shows the defect is supported, a run that does not is unsupported-opinion and is never recorded as fixed, and the supervisor refuses a proof-by-run assessment that is inconsistent or bound to another commit.
- The Evidence gate catalog gains a built-in `git-history` entry, so "did this change add it, or was it already on the base?" is settled by one run: the controller runs `evidence-gate.py git-history --path <path>`, which computes the change base itself, accepts only a path the change touched outside `.context/`, reads committed objects only through the hardened Git helper, and refuses partial clones, alternates, and Git settings that run a program. The finding adjudicator keeps only Read and Grep.
