## Highlights
- The shared file-safety helper can now create or update a file inside a repository without following links or leaving a half-written file behind.

## Changed
- Added `write_confined_regular_file` to the shared file-safety helper. It creates a missing file or rewrites an existing one in place only when the file still has the digest you expect, and refuses links, special files and paths outside the root.
