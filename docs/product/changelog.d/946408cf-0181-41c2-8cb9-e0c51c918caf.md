## Highlights
- Breaking: full-mode work-loop now runs through the execution supervisor. The old phase engine, the cohort scripts, the wave-decision schema, and the full-mode engine reference are removed. A run started under the old engine is re-derived from the spec, plan, Git history, evidence, and review facts rather than resumed in place, so its tasks count as incomplete until the loop re-runs or replans them; reverse the change by reinstalling the prior Core release.
- Breaking: `review-artifact.py` no longer reads a spec's cohort state. `inspect` and `record` now require `--run-id <uuid>`, and the `spec_dir` positional is gone, so a call that passes it fails. Its diagnostics use the `review-artifact:` prefix. `classify` and `raw-classify` are unchanged.
