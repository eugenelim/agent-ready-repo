## Highlights
- `experience-reviewer` anchors every finding: a backticked `path:line` for a finding in a file, otherwise `Where: <screen/stage/brief>` with no period in the location, so the review classifier parses each finding as written.
- `experience-reviewer` returns a typed report on request — one `json` block with `terminal_status` and the `finding.v1` fields, carrying only material findings — so a controller no longer reshapes its prose by hand. Without that request its output is unchanged, including the `SHIP IT` clean verdict.
