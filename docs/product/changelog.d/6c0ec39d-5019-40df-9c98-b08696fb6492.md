## Highlights
- Architect-diagram can export a saved Mermaid diagram to an editable draw.io file on request.

## Changed
- `architect-diagram` can now turn a saved Mermaid diagram into an editable draw.io file when you ask for one. It uses the draw.io desktop command-line tool.
- If that tool is missing, the skill offers one package-manager install command and runs it only after you say yes. If you decline, it writes the draw.io file itself.
- Mermaid is still the default output and stays the source of the diagram.
