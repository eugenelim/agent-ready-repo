## Highlights
- Ask new-rfc to set up governance, and it drafts GOVERNANCE.md, CODEOWNERS or a charter link and writes only after you confirm the exact preview.

## Changed
- `new-rfc` gains a `governance` mode that drafts a `GOVERNANCE.md`, a `CODEOWNERS` file or a charter link from the handles you supply. It writes only after you confirm the exact preview, and writes nothing that changes the decision model or ownership until you name the approval.
- The pack ships a how-to guide for the mode and no standing permission for its `write` command.
