## Highlights
- work-loop's multi-feature trigger now splits a bundle of tasks shown to be independent into one unit per task, instead of sending the whole bundle through full mode.
- work-loop runs a plain edit to an existing agent-guidance file in light mode, with a test that checks the edited section's key phrases, unless the edit changes a tool surface, an authority or gate, a security boundary, or a published schema.
- Nine new evals cover bundle splitting and plain guidance edits.

## Changed
- `work-loop`: the multi-feature risk trigger splits a bundle into one unit per task when all three parts of the independence test pass, merges nothing until every unit passes the diff check, and falls back to full mode otherwise; the "prose that is the rule" sentence treats an edit to an existing agent-guidance file as a trigger only when it changes a tool surface, an authority or gate, a security boundary, or a published schema.
- `work-loop` `references/light-mode.md`: gains the bundle-splitting and plain-guidance-edit sections, and the durability row is narrowed to match.
- `work-loop` evals: nine new cases for bundle splitting and guidance edits.
