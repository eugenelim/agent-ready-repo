## Highlights
- work-loop's multi-feature trigger now splits a bundle of tasks shown to be independent into one unit per task, instead of sending the whole bundle through full mode.
- A plain edit to an existing agent-guidance file runs in light mode with a section-scoped content-pin test, unless it changes a tool surface, an authority or gate, a security boundary, or a published schema.
- Nine new evals cover bundle splitting and plain guidance edits.

## Changed
- `work-loop`: the multi-feature risk trigger splits a bundle into one unit per task when the three-part independence test and the diff check pass, merges nothing until every unit passes, and falls back to full mode otherwise; the guidance-file trigger narrows to the four surfaces above.
- `work-loop` `references/light-mode.md`: gains the bundle-splitting and plain-guidance-edit sections, and the durability row is narrowed to match.
- `work-loop` evals: nine new cases for bundle splitting and guidance edits.
