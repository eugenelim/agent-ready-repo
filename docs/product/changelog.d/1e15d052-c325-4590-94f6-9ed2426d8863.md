## Highlights
- Adopters move the last registry entries and refresh's role policy (.work-intake.toml) with one repair run.

## Changed
- The repair plan gains `captured-entry-drop`, which removes a captured registry entry that holds only membership or a slug once its captured-item file exists, moving any legacy `needs` into that file's `Depends on:` header first. It never writes the captured file itself.
- The repair plan gains `refresh-policy-move`, which moves the registry's refresh authorization table into `.work-intake.toml` and never overwrites an existing `.work-intake.toml`.
- Refresh reads its role policy from `.work-intake.toml` and refuses with `invalid_refresh_policy` without it; its `policy_digest` is computed from that file.
- Deferral anchors now resolve through captured-item files.
