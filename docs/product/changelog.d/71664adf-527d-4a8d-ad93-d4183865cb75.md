## Highlights
- Reviews in the `github-pr` skill now challenge a pull request's design and spec as well as its code, add a security-boundary lens, and check each comment against the code before it is drafted.
- When the agent adopts a contributor's pull request, a behavior fix now starts with a failing test, then the fix and your named gates, then an independent security review when the change touches a security boundary.
