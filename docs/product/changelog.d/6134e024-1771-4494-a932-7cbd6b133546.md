## Highlights
- The effect broker now replaces an operation ID or grant ID that is not a non-empty string before it builds an audit event, so a malformed identifier is never stored. When the content-safety check refuses an allow event's identifiers, the effect is refused with `denied-audit-sink-unavailable`, as for any allow event that cannot be stored, and the refusal is still audited, with both identifiers redacted.
- The execution supervisor now refuses a `review-role` result that carries both a review report and a selection with `result-fact-refused`, before reading any state. Such a result was already refused later as `invalid-result`.
- The execution supervisor now stops on Git older than 2.32 with a usage error whose detail starts `unsupported-git-version`. Older Git ignores the empty `GIT_CONFIG_GLOBAL` the supervisor sets, so its Git calls would still read your global config.
