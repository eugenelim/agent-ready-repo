## Highlights
- Run reviewed non-production releases through protected GitHub Actions jobs with digest-bound human approval and immutable audit evidence.

## Added

- `github_release.py` checks readiness, admission/run/approval binding, execution budgets, live protection, reconciliation and immutable audit read-back without network or subprocess calls.
- The GitHub Actions reference owns capture recipes, cloud setup, refusal codes and recovery limits. Prepare, deploy and reusable deploy-job assets provide the protected execution path.
- An adopter how-to and admission reference explain setup through cleanup and the final human decision. Release-loop evals cover blocking, refusal, approval and recovery paths.
