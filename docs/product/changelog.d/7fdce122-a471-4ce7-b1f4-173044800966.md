## Highlights
- The finding-adjudication commands `classify`, `raw-classify`, `inspect`, and `record` now live in `review-artifact.py`. They print exactly what the `loop-cohort.py review` verbs print, and those verbs keep working.
- Without cohort state, `review-artifact.py record --run-id <uuid>` keeps one `record` file per review round under `.context/reviews/<run-id>/` and counts the review budget from those files. Lifting the cap needs an `owner` authority reference.
- The reviewer roster, each role's boundary and fallback, and the high-risk definition now also live in `review-rules.json`. A check fails if they drift from the work-loop skill text.
- The supervisor, still dark-launched, now picks reviewers from that rules file and a recorded selection. It closes review only when structured review readiness says so, and it records repair, `fixed-by`, and `accept-risk` decisions.
- Policy families can now be selected by supervisor stage, or by the new `PRE-APPROVAL` constant. Each key selects what its engine states select today.
