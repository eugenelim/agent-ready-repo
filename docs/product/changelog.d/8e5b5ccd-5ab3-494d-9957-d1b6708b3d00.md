## Highlights
- The status report now lists captured items from their own files under docs/product/captured/, and reports a file whose Status:, Kind:, or other field is invalid.
- A captured item registered outside docs/product/captured/ is now refused with unmigrated_captured_item, and repair-plan's captured-to-file operation writes each item's own file and re-points its entry, after you confirm the plan.
- work-loop routes a supplied slug whose captured-item file carries a Type: line to its shaping skill.
