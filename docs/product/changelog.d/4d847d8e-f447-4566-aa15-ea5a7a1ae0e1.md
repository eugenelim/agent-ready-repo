## Highlights
- Picking an item in the offline intent view now shows a ready-to-paste prompt that starts the named skill on that file, copied with one click or selected for you to copy by hand.

## Changed
- The detail panel's "Next step" in the `navigate-intents` offline view gains a prompt block and a "Copy prompt" button for the seven next steps that start a skill. The prompt is one fixed sentence plus the item's file path, nothing else from the record. When the browser refuses the clipboard, the prompt is selected so you can copy it by hand. When a path is too long or uses characters a prompt cannot carry safely, the panel says so in plain words and shows no prompt.
