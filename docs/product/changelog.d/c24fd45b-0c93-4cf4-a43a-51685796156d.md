## Highlights
- Author and reconcile Terraform using your own repository instructions and accepted decisions, with checked governance and review evidence.

## Added
- Local `authoring_gate.py` commands discover governing sources and check governance summaries and exact saved-plan review records.
- One canonical infrastructure-review checklist covers decisions, schema, plan effects, privilege, policy, state impact and reversibility.

## Changed
- Stage 0 uses repository instructions, accepted decisions and explicit inputs directly. Optional integrations cannot override refusals or enable a weaker fallback.
- Reconciliation uses the same checked governance summary and retains its managed-resources-only limit.
- Guides and skill evals cover the direct path, stop outcomes and optional integrations.
